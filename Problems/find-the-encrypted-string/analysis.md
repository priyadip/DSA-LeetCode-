# 3210. Find the Encrypted String - Solution Analysis

## Problem Understanding
Given a string `s` of length `n` (1 ≤ n ≤ 100) and an integer `k` (1 ≤ k ≤ 10��), produce a new string where the character at index `i` becomes the character that is `k` positions ahead of `i` in `s`, wrapping around cyclically. The output is exactly the original string rotated left by `k` positions. All characters are lowercase letters; duplicates and any `k` are allowed.

## Approach
The solution uses **direct index mapping with modular arithmetic**. For each position `i` in the result, the source character is at index `(i + k) % n` in the original string. This is a classic cyclic shift (left rotation by `k`). A brute-force simulation would also be O(n) but might use an auxiliary array; the chosen approach computes each target character on the fly. The key insight is that the encrypted string is simply `s` rotated left by `k % n`.

## Algorithm
1. Let `n = len(s)`.
2. Initialise an empty string `rs`.
3. For each index `i` from `0` to `n-1`:
   - Compute `j = (i + k) % n`.
   - Append `s[j]` to `rs`.
4. Return `rs`.

## Line-by-Line Explanation
- `rs = ''`: Initialise the accumulator for the encrypted string.
- `for i in range(n := len(s)):`: Iterate over all indices `i`; the walrus operator assigns `n = len(s)` inline.
- `rs += s[(i+k) % n]`: Compute the cyclic source index, fetch that character, and concatenate it to `rs`.
- `return rs`: Return the fully built encrypted string.

## Dry Run
Example: `s = "dart"`, `k = 3`, `n = 4`.

| Step | i | (i+k)%n | s[(i+k)%n] | rs    |
|------|---|---------|------------|-------|
| 1    | 0 | 3       | 't'        | 't'   |
| 2    | 1 | 0       | 'd'        | 'td'  |
| 3    | 2 | 1       | 'a'        | 'tda' |
| 4    | 3 | 2       | 'r'        | 'tdar'|

Result: `"tdar"`.

## Complexity
- **Time**: O(n²) in the worst case because string concatenation `+=` in a loop creates a new string each iteration (Python strings are immutable). With `n ≤ 100` this is negligible, but asymptotically it is quadratic.
- **Space**: O(n) for the output string `rs`.

## Edge Cases
- `k` larger than `n`: modulo reduces it correctly.
- `k` multiple of `n`: `(i + k) % n == i`, so the string remains unchanged (e.g., `s = "abc", k = 3` → `"abc"`).
- Single-character string: `n = 1`, `(i + k) % 1 = 0`, returns the same character.
- All characters identical: rotation produces the same string (Example 2).
- Maximum constraints (`n = 100, k = 10��`): handled without issue.

## Possible Improvements
- **Use list comprehension and `join`** to achieve guaranteed O(n) time:  
  `return ''.join(s[(i + k) % n] for i in range(len(s)))`.
- **Use slicing** for a direct left rotation (also O(n) and more readable):  
  `k %= n; return s[k:] + s[:k]`.
- **Extract `n` before the loop** for clarity: `n = len(s); for i in range(n): ...`.
