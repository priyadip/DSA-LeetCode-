# 3870. Count Commas in Range - Solution Analysis

## Problem Understanding
We are given an integer `n` (1 ≤ n ≤ 100,000) and must return the total number of commas appearing when all integers from 1 to `n` are written in standard formatting (commas every three digits from the right). Numbers with fewer than four digits have no commas. The constraint `n ≤ 10^5` is crucial: it guarantees that any number ≥ 1000 has at most six digits and therefore contains exactly one comma.

## Approach
The solution uses a **direct mathematical formula** derived from the observation that, within the given constraints, every integer from 1000 up to `n` contributes exactly one comma. The brute‑force approach would iterate over each number, format it, and count commas, costing O(n·d) time (d = digit count). The formula reduces this to O(1) by simply counting how many numbers in the range have at least four digits.  
**Key insight:** For `n ≤ 100,000`, all numbers ≥ 1000 have exactly one comma, so the answer is `max(0, n - 999)`.

## Algorithm
1. If `n < 1000`, return `0` (no number in the range has four digits).
2. Otherwise, return `n - 999` (the count of integers from 1000 to `n` inclusive).

## Line-by-Line Explanation
- `if n < 1000:` – checks whether the upper bound is below the first number that requires a comma.
- `return 0` – no commas appear in the range `[1, n]`.
- `return n - 999` – computes the quantity of numbers from 1000 to `n`; each contributes one comma.

## Dry Run
Example: `n = 1002`

| Step | Condition | Computation | Result |
|------|-----------|-------------|--------|
| 1    | 1002 ≥ 1000 | 1002 - 999 | 3 |

The three numbers 1000, 1001, 1002 each contain one comma → total 3.

## Complexity
- Time: O(1) – only a constant-time comparison and subtraction.
- Space: O(1) – no auxiliary data structures.

## Edge Cases
- `n = 999` → returns 0 (all numbers have ≤ 3 digits).
- `n = 1000` → returns 1 (only "1,000" has a comma).
- `n = 100,000` → returns 99,001 (every number from 1000 to 100,000 has exactly one comma).
All cases are covered by the constraints; no other boundary conditions exist.

## Possible Improvements
The solution is already optimal for the given constraints (O(1) time and space). If the upper bound were larger (e.g., `n ≤ 10^15`), a more general formula summing commas per digit-length group would be needed, but that is unnecessary here.
