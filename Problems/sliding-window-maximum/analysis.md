# 239. Sliding Window Maximum - Solution Analysis

## Problem Understanding
Given an integer array `nums` and a window size `k`, return an array of the maximum value in each contiguous subarray of length `k` as the window slides from left to right. The input length `n` can reach 10^5, so an O(n·k) brute force is infeasible. Elements may be negative or duplicated; the output order must match the window positions.

## Approach
**Monotonic Deque** (monotonic decreasing queue).  
A brute-force scan of each window costs O(n·k). The monotonic deque reduces this to O(n) by storing only indices of elements that can still become a window maximum, kept in decreasing order of their values. The front of the deque always holds the index of the current window's maximum.  
**Key insight:** any element smaller than a newer element to its right can never be the maximum once that newer element enters the window, so it can be discarded immediately.

## Algorithm
1. Initialise empty list `ans` and empty deque `dq` (stores indices).
2. For each index `i` from `0` to `len(nums)-1`:
   a. While `dq` is not empty and `dq[0] <= i - k`, pop from left (expired indices).
   b. While `dq` is not empty and `nums[dq[-1]] <= nums[i]`, pop from right (dominated indices).
   c. Append `i` to `dq`.
   d. If `i >= k - 1`, append `nums[dq[0]]` to `ans`.
3. Return `ans`.

## Line-by-Line Explanation
- `ans = []`: collects the maximum of each completed window.
- `dq = deque()`: double-ended queue holding indices in decreasing order of their corresponding values.
- `for i in range(len(nums)):`: iterate over every array index.
- `while dq and dq[0] <= i - k:`: remove indices that have fallen out of the left side of the window.
- `dq.popleft()`: discard the expired leftmost index.
- `while dq and nums[dq[-1]] <= nums[i]:`: remove indices whose values are ≤ the current value; they can never be a maximum while `nums[i]` is in the window.
- `dq.pop()`: discard the dominated rightmost index.
- `dq.append(i)`: add current index as a candidate for current and future windows.
- `if i >= k - 1:`: the first window ends at index `k-1`; from here on every step completes a window.
- `ans.append(nums[dq[0]])`: the front of the deque holds the index of the maximum in the current window.
- `return ans`: all window maximums in order.

## Complexity
- **Time:** O(n) — each index is pushed once and popped at most once.
- **Space:** O(k) — the deque holds at most `k` indices (the window size).

## Edge Cases
- **k = 1:** every element forms its own window; deque never exceeds size 1, output equals input.
- **k = n:** single window covering the whole array; deque maintains the global maximum.
- **All equal elements:** the `<=` condition keeps only the newest index of each value, which is correct because older equal values expire first.
- **Strictly decreasing array:** deque grows to size `k` with no right pops; front always the leftmost (maximum).
- **Strictly increasing array:** deque stays size 1; each new element evicts all previous ones.
- **Negative numbers:** handled naturally by value comparisons.
