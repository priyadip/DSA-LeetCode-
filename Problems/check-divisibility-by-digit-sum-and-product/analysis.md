# 3622. Check Divisibility by Digit Sum and Product - Solution Analysis

## Problem Understanding
Given a positive integer `n` (1 ≤ n ≤ 10⁶), we must decide whether `n` is divisible by the sum of its digit sum and digit product. The digit sum is the sum of all decimal digits of `n`; the digit product is the product of those digits. Since `n` is positive, the digit sum is at least 1, so the divisor (sum + product) is never zero. The constraints are tiny (at most 7 digits), so a direct digit-by-digit computation is fully sufficient.

## Approach
The solution uses **digit extraction via modulo and integer division** – a standard pattern for problems that require per-digit aggregation. The brute-force approach is exactly this: iterate over each digit once, accumulate the sum and product, then test divisibility. No alternative algorithm can avoid examining every digit, so this single-pass method is optimal. The key insight is that both the sum and product can be computed simultaneously in one loop by repeatedly taking `n % 10` and `n //= 10`.

## Algorithm
1. Save the original value of `n` in `m` because the loop will destroy `n`.
2. Initialise `su = 0` (digit sum) and `pr = 1` (digit product).
3. While `n` is not zero:
   - Extract the last digit `d = n % 10`.
   - Add `d` to `su`.
   - Multiply `pr` by `d`.
   - Remove the last digit: `n //= 10`.
4. After the loop, compute `total = su + pr`.
5. Return `True` if `m % total == 0`, otherwise `False`.

## Line-by-Line Explanation
- `su, pr = 0, 1`: initialise accumulators for digit sum and product.
- `m = n`: preserve the original input for the final divisibility check.
- `while n:`: loop until all digits have been processed (when `n` becomes 0).
- `d = n % 10`: isolate the least significant digit.
- `su += d`: accumulate the digit sum.
- `pr *= d`: accumulate the digit product.
- `n //= 10`: drop the processed digit.
- `return ((m % (su + pr)) == 0)`: check divisibility of the original number by the sum of digit sum and product.

## Complexity
- **Time**: O(d) where d is the number of digits of `n`. With `n ≤ 10⁶`, d ≤ 7, so effectively O(1).
- **Space**: O(1) – only a few integer variables are used.

## Edge Cases
- **Zero digit**: e.g., `n = 10` → digits 1,0 → sum=1, product=0 → total=1 → `10 % 1 == 0` → `True`. The product becomes 0, but the divisor remains positive because sum ≥ 1.
- **Single digit**: `n = 1` → sum=1, product=1 → total=2 → `1 % 2 != 0` → `False`.
- **Maximum input**: `n = 1_000_000` → digits 1,0,0,0,0,0,0 → sum=1, product=0 → total=1 → divisible → `True`.
- **All digits equal**: handled naturally by the loop.
- **No valid answer**: e.g., `n = 23` (Example 2) correctly returns `False`.

All cases are reachable under the given constraints (n ≥ 1).
