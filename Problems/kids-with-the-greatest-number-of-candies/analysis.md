# 1431. Kids With the Greatest Number of Candies - Solution Analysis

## Problem Understanding
Given an array `candies` where each element represents a kid's candy count and an integer `extraCandies`, determine for each kid whether giving them all `extraCandies` would make their total at least as large as the current maximum in the array. The output is a boolean array of the same length. Constraints are small (n ≤ 100, values ≤ 100), so a single pass to find the max and a second pass to compare is optimal.

## Approach
The solution uses a **single-pass maximum + element-wise comparison** pattern. The brute force would be, for each kid, to simulate giving them the extra candies and then scan the whole array to check if they are the greatest, costing O(n²). The chosen approach observes that the condition "candies[i] + extraCandies ≥ max(candies)" is equivalent and only requires knowing the global maximum once. The key insight: a kid can reach the greatest count iff their current count plus the extra candies meets or exceeds the existing maximum.

## Algorithm
1. Compute `m = max(candies)`, the current greatest number of candies any kid has.
2. Iterate through each `c` in `candies` and evaluate the boolean expression `c + extraCandies >= m`.
3. Collect the results into a list and return it.

## Line-by-Line Explanation
- `m = max(candies)`: Finds the global maximum candy count in O(n) time.
- `return [c+extraCandies >= m for c in candies]`: List comprehension that builds the answer by checking the condition for each kid in a single pass.

## Dry Run
Using Example 1: `candies = [2,3,5,1,3]`, `extraCandies = 3`.

Output: `[true, true, true, false, true]`.

## Complexity
- Time: O(n), where n = len(candies). One pass for `max`, one pass for the comprehension.
- Space: O(n) for the output list (required by the problem). Auxiliary space is O(1).

## Edge Cases
- **All kids have equal candies**: `max` equals every element; all results become `true` because `c + extraCandies >= c` holds (extraCandies ≥ 1 by constraints).
- **Single maximum, others far behind**: Only the kid(s) at or near the max return `true`; works correctly.
- **Minimum constraints (n=2)**: Both passes handle length 2 without issue.
- **Large extraCandies**: If `extraCandies` is large enough, all kids satisfy the condition; the comparison handles it naturally.
