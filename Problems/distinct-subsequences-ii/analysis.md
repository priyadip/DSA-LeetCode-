# 940. Distinct Subsequences II - Solution Analysis

## Problem Understanding
Given a string `s` of lowercase letters (length up to 2000), count the number of distinct non-empty subsequences. A subsequence preserves relative order but may skip characters. The answer is returned modulo \(10^9+7\). The key challenge is avoiding overcounting when characters repeat.

## Approach
The solution uses **Dynamic Programming with a last-occurrence array**.  
Brute force would enumerate all \(2^n\) subsequences and deduplicate, which is exponential.  
The DP insight: when appending a new character `ch`, every existing subsequence can either exclude or include `ch`, doubling the count. However, if `ch` appeared before, the subsequences formed by adding `ch` to the subsequences that existed *just before its last occurrence* would be duplicated. Subtracting that stored count eliminates duplicates. This yields \(O(n)\) time and \(O(1)\) space (alphabet size 26 is constant).

**Key insight:** The number of distinct subsequences after processing a character equals twice the previous count minus the count of subsequences that existed before the previous occurrence of the same character.

## Algorithm
1. Set `MOD = 10**9 + 7`.
2. Initialize `dp = 1` (counts distinct subsequences including the empty string).
3. Initialize `last = [0] * 26` to store the `dp` value *before* the last occurrence of each letter.
4. For each character `ch` in `s`:
   - `i = ord(ch) - ord('a')`.
   - `new_dp = (2 * dp - last[i]) % MOD`.
   - `last[i] = dp` (save current `dp` for the next occurrence of `ch`).
   - `dp = new_dp`.
5. Return `(dp - 1) % MOD` to exclude the empty subsequence.

## Line-by-Line Explanation
- `MOD = 10**9 + 7`: Modulo constant.
- `dp = 1`: Start with the empty subsequence.
- `last = [0] * 26`: Tracks the `dp` value before the last occurrence of each letter; initially zero.
- `for ch in s:`: Process each character.
- `i = ord(ch) - ord('a')`: Map character to index 0–25.
- `new_dp = (2 * dp - last[i]) % MOD`: Double the count (each subsequence either takes or skips `ch`), subtract the count that would be duplicated (subsequences existing before the last `ch`).
- `last[i] = dp`: Record the current `dp` (before update) so the next occurrence of `ch` can subtract it.
- `dp = new_dp`: Update the running count.
- `return (dp - 1) % MOD`: Remove the empty subsequence and apply modulo.

## Dry Run
Trace with `s = "aba"` (expected output 6).

| Step | ch | i | dp (before) | last[i] (before) | new_dp = (2*dp - last[i]) % MOD | last[i] updated to | dp (after) |
|------|----|---|-------------|------------------|--------------------------------|-------------------|------------|
| 0 (init) | – | – | 1 | [0]*26 | – | – | 1 |
| 1 | 'a' | 0 | 1 | 0 | (2*1 - 0) = 2 | last[0]=1 | 2 |
| 2 | 'b' | 1 | 2 | 0 | (2*2 - 0) = 4 | last[1]=2 | 4 |

| End | – | – | – | – | – | – | return (7-1)=6 |

Result matches the 6 distinct subsequences: "a", "b", "ab", "aa", "ba", "aba".

## Complexity
- **Time:** \(O(n)\), where \(n = \text{len}(s)\). Each character is processed once with \(O(1)\) work.
- **Space:** \(O(1)\) (the `last` array has fixed size 26).

## Edge Cases
- **Single character** (e.g., `"a"`): `dp` becomes 2, returns 1. Correct.
- **All identical characters** (e.g., `"aaa"`): `dp` evolves 1→2→3→4, returns 3. Correct (subsequences: "a", "aa", "aaa").
- **All distinct characters** (e.g., `"abc"`): `dp` doubles each step (1→2→4→8), returns 7. Correct.
- **Maximum length 2000**: \(O(n)\) easily fits; modulo prevents overflow.
- The solution correctly handles duplicates via the `last` array. If the alphabet were larger, `last` would need to grow, but constraints fix it to lowercase.

The solution is already optimal for the given constraints: \(O(n)\) time and \(O(1)\) space. Variable names (`dp`, `last`, `MOD`) are clear and conventional. No redundant passes or structures exist. No further improvements are necessary.
