# 2958. Length of Longest Subarray With at Most K Frequency - Solution Analysis

## Problem Understanding
Given an integer array `nums` and integer `k`, find the length of the longest contiguous subarray where every element's frequency is at most `k`. The array length is up to 10^5, values up to 10^9, and `k` is at least 1. Order matters (subarray, not subset), duplicates are central to the constraint, and the answer always exists because any single element is valid when `k >= 1`.

## Approach
**Sliding Window (Two Pointers)**. The brute force would check all O(n^2) subarrays and count frequencies in O(n) each, giving O(n^3) or O(n^2) with prefix counts — too slow for n=10^5. The sliding window maintains a window `[left, right]` that is always *good* (all frequencies ≤ k). We expand `right` greedily; when adding `nums[right]` violates the condition (its count exceeds `k`), we shrink `left` until the window becomes good again. Because `left` only moves forward, each element enters and leaves the window once.  
**Key insight**: The condition "all frequencies ≤ k" is monotonic — shrinking the window never introduces a new violation, so a simple while-loop on the offending element suffices.

## Algorithm
1. Initialise a hash map `freq` for element counts, `left = 0`, `ans = 0`.
2. Iterate `right` from 0 to `len(nums)-1`:
   a. Increment `freq[nums[right]]`.
   b. While `freq[nums[right]] > k`:
       - Decrement `freq[nums[left]]`.
       - Increment `left`.
   c. Update `ans = max(ans, right - left + 1)`.
3. Return `ans`.

## Line-by-Line Explanation
- `freq = defaultdict(int)`: frequency map, default 0 for unseen keys.
- `left = 0`: left boundary of the current window.
- `ans = 0`: best length found so far.
- `for right in range(len(nums)):`: expand window to the right, one element per iteration.
- `freq[nums[right]] += 1`: include the new element in the window.
- `while freq[nums[right]] > k:`: the just-added element now violates the limit; shrink from the left until it no longer does.
- `freq[nums[left]] -= 1`: remove the leftmost element from the window.
- `left += 1`: advance left boundary.
- `ans = max(ans, right - left + 1)`: window `[left, right]` is good; record its length.
- `return ans`: longest good subarray length.

## Complexity
- **Time**: O(n). Each index is visited once by `right` and at most once by `left`; all map operations are O(1) average.
- **Space**: O(m) where m is the number of distinct values in the current window, bounded by min(n, distinct values in `nums`). In worst case O(n).

## Edge Cases
- **All elements identical, k < n**: e.g., `[5,5,5,5,5]`, `k=2`. Window expands until count hits 3, then `left` tracks `right-1`, yielding answer `k`. Works correctly.
- **k = 1**: Reduces to longest subarray with all distinct elements. The while-loop shrinks until the duplicate is removed; correct.
- **k >= n**: The while condition never triggers; `left` stays 0, answer becomes `n`. Correct.
- **Single element**: Loop runs once, `ans = 1`. Correct.
- **Large values (10^9)**: `defaultdict` handles sparse keys without array allocation; no issue.

## Possible Improvements
The solution is already optimal in time (O(n)) and space (O(distinct)) for the given constraints. No asymptotic improvement exists. A minor readability tweak: rename `freq` to `count` and `ans` to `max_len` for clarity, but this is purely stylistic. The logic is tight and correct.
