# 3090. Maximum Length Substring With Two Occurrences - Solution Analysis

## Problem Understanding
We need the maximum length of a contiguous substring in which every character appears at most twice. The input is a lowercase string of length 2 to 100. Order matters (substring, not subsequence), duplicates are allowed up to a frequency of 2, and the small length bound permits O(n²) brute force, though a linear solution exists.

## Approach
The solution uses the **Sliding Window** (two pointers) pattern. A brute-force check of all O(n²) substrings with O(n) validation would be O(n³) or O(n²) with prefix sums; sliding window reduces this to O(n) by maintaining a valid window `[l, r]` and expanding `r` while contracting `l` only when the newly added character violates the "at most two" constraint. The key insight: when a character's count exceeds 2, we must advance `l` until that character's count drops back to 2, because only the current character can be over the limit (all others were already ≤2 before adding `s[r]`).

## Algorithm
1. Initialize a frequency array `cn[26] = {0}`, left pointer `l = 0`, and answer `ans = 0`.
2. For each right pointer `r` from `0` to `n-1`:
   a. Increment the count of `s[r]`.
   b. While the count of `s[r]` exceeds 2:
       i. Decrement the count of `s[l]`.
       ii. Increment `l`.
   c. Update `ans = max(ans, r - l + 1)`.
3. Return `ans`.

## Line-by-Line Explanation
- `cn = [0]*26`: fixed-size array tracking frequencies of 'a'–'z' in the current window.
- `n, l, ans = len(s), 0, 0`: store string length, left boundary, and best length found.
- `for r in range(n):`: expand window to the right, one character per iteration.
- `x = ord(s[r]) - 97`: map current character to index 0–25.
- `cn[x] += 1`: include `s[r]` in the window.
- `while cn[x] > 2:`: if this character now appears three times, shrink from the left.
- `cn[ord(s[l]) - 97] -= 1`: remove the leftmost character from the frequency count.
- `l += 1`: move left boundary rightward.
- `if r-l+1 > ans:`: current window is valid; check if it improves the maximum.
- `ans = r-l+1`: record new maximum length.
- `return ans`: final answer.

## Complexity
- **Time:** O(n) – each character is added once by `r` and removed at most once by `l`; `n = len(s) ≤ 100`.
- **Space:** O(1) – the frequency array has fixed size 26, independent of input size.

## Edge Cases
- **All identical characters** (e.g., `"aaaa"`): window expands to two `'a'`, then `l` tracks `r-1`, yielding max length 2.
- **Whole string valid** (e.g., `"abc"`): `l` never moves, answer is `n`.
- **Multiple maximum substrings**: any is fine; we only track length.
- **Minimum length 2**: guaranteed by constraints, so empty-string handling is unnecessary.

## Possible Improvements
The solution is already optimal in both time (O(n)) and space (O(1)) for the given constraints. Readability could be slightly improved by renaming `cn` → `count`, `l` → `left`, `ans` → `max_len`, but the logic is clear as written. No algorithmic improvement is needed.
