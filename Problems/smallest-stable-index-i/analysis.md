# 3903. Smallest Stable Index I - Solution Analysis

## Problem Understanding
We need the smallest index `i` such that `max(nums[0..i]) - min(nums[i..n-1]) ≤ k`. The array length is at least 1, values are non‑negative up to 10⁹, and `k` is non‑negative up to 10⁹. Order matters – we return the first index satisfying the condition. Duplicates and zeros are allowed; the logic works for any integers. The small constraint (`n ≤ 100`) permits even quadratic solutions, but the chosen approach is linear.

## Approach
The solution uses **prefix/suffix precomputation** (prefix maximum and suffix minimum arrays). This pattern fits because the instability score at each index depends only on the running maximum from the left and the running minimum from the right, both of which can be computed independently in linear time.  
Brute force would recompute the max and min for every index, costing O(n²). The chosen approach reduces this to O(n) time and O(n) space by scanning once forward for prefix maxima and once backward for suffix minima.  
**Key insight:** The instability score at `i` is completely determined by `prefix_max[i]` and `suffix_min[i]`, which can be precomputed in two linear passes.

## Algorithm
1. Compute `prefix_max` where `prefix_max[i] = max(nums[0..i])` using `itertools.accumulate` with `max`.
2. Compute `suffix_min` where `suffix_min[i] = min(nums[i..n-1])` by reversing `nums`, accumulating with `min`, then reversing the result.
3. Iterate `i` from `0` to `n-1`:
   - If `prefix_max[i] - suffix_min[i] ≤ k`, return `i`.
4. If no index satisfies the condition, return `-1`.

## Line-by-Line Explanation
- `n = len(nums)`: stores the array length (unused later, harmless).
- `prefix_max = list(accumulate(nums, max))`: builds the prefix maximum array in one forward pass.
- `suffix_min = list(accumulate(nums[::-1], min))[::-1]`: reverses `nums`, computes running minima on the reversed array (which correspond to suffix minima from right to left), then reverses back to align with original indices.
- `for i in range(len(nums)):`: checks each index in order.
- `if prefix_max[i] - suffix_min[i] <= k:`: evaluates the instability score against `k`.
- `return i`: returns the first (smallest) stable index.
- `return -1`: no stable index found.

## Dry Run
Example 1: `nums = [5,0,1,4]`, `k = 3`.

| Step | i | nums[i] | prefix_max | suffix_min | prefix_max[i] - suffix_min[i] | Action |
|------|---|---------|------------|------------|-------------------------------|--------|
| 1    | 0 | 5       | 5          | 0          | 5                             | continue |
| 2    | 1 | 0       | 5          | 0          | 5                             | continue |
| 3    | 2 | 1       | 5          | 1          | 4                             | continue |
| 4    | 3 | 4       | 5          | 4          | 1 ≤ 3                         | return 3 |

`prefix_max = [5,5,5,5]` (from `accumulate(nums, max)`).  
`suffix_min`: reverse → `[4,1,0,5]`, accumulate min → `[4,1,0,0]`, reverse → `[0,0,1,4]`.

## Complexity
- **Time:** O(n) – one pass for `prefix_max`, one pass for `suffix_min`, and one pass for the final loop. `n = len(nums)`.
- **Space:** O(n) – two auxiliary arrays of length `n`.

## Edge Cases
- **Single element** (`n = 1`): `prefix_max[0] = suffix_min[0] = nums[0]`, difference 0 ≤ k (since k ≥ 0) → returns 0. Works.
- **All elements equal**: difference always 0 → returns 0 if k ≥ 0.
- **No stable index** (Example 2): loop finishes, returns -1.
- **k = 0**: requires exact equality of prefix max and suffix min; handled correctly.
- **Large values** (up to 10⁹): Python integers handle them without overflow.
- **Already sorted ascending**: `prefix_max[i] = nums[i]`, `suffix_min[i] = nums[i]` → difference 0 → returns 0.
- **Already sorted descending**: `prefix_max` constant, `suffix_min` constant → difference constant; works.
