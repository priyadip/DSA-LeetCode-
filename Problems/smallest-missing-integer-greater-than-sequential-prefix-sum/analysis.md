# 2996. Smallest Missing Integer Greater Than Sequential Prefix Sum - Solution Analysis

## Problem Understanding
We are given an array `nums` and must find the longest prefix where each element equals the previous element plus one (a sequential prefix). The sum of this prefix is computed. The answer is the smallest integer greater than or equal to this sum that does not appear anywhere in `nums`. Constraints are tiny (`n ≤ 50`, values `≤ 50`), so any linear or quadratic approach works, but the solution uses a single pass and a hash set for O(1) lookups.

## Approach
The algorithmic pattern is **linear scan + hash set lookup**.  
A brute-force approach would check every possible prefix for sequentiality (O(n²)) and then scan for the missing integer (O(n·maxVal)). The chosen approach scans once from the left to build the longest sequential prefix sum (O(n)), stores all values in a set (O(n)), then increments the sum until it finds a value not in the set (at most O(n) increments because there are only n distinct values). The key insight: the longest sequential prefix must start at index 0, so we only need one forward pass; after that, the missing integer is simply the first gap at or above that sum.

## Algorithm
1. Initialise `prefixSum` with `nums[0]`.
2. Iterate `i` from 1 to `len(nums) - 1`:
   - If `nums[i] == nums[i-1] + 1`, add `nums[i]` to `prefixSum`.
   - Otherwise, break the loop (the sequential prefix has ended).
3. Insert all elements of `nums` into a hash set `s`.
4. While `prefixSum` is in `s`, increment `prefixSum` by 1.
5. Return `prefixSum`.

## Line-by-Line Explanation
- `prefixSum = nums[0]`: Start the sum with the first element; a single-element prefix is always sequential.
- `for i in range(1, len(nums)):`: Scan the rest of the array.
- `if nums[i] == nums[i - 1] + 1:`: Check if the current element continues the sequential run.
- `prefixSum += nums[i]`: Extend the prefix sum.
- `else: break`: Stop at the first break in sequentiality; the longest prefix is found.
- `s = set(nums)`: Build a hash set for O(1) membership tests.
- `while prefixSum in s:`: Advance past any values that exist in the array.
- `prefixSum += 1`: Increment to the next candidate.
- `return prefixSum`: The first missing integer ≥ original prefix sum.

## Dry Run

| 0 | - | - | - | - | 1 | initialise |

| 3 | 3 | 2 | 3 | 2 == 3+1 ✗ | 6 | break |

Set `s = {1,2,3,5}`.  
`prefixSum = 6`; `6 not in s` → loop skipped. Return 6.

| Step | i | nums[i] | nums[i-1] | Condition | prefixSum | Action |
|------|---|---------|-----------|-----------|-----------|--------|

Set `s = {1,3,4,5,12,13,14}`.  
`prefixSum = 12`; `12 in s` → 13; `13 in s` → 14; `14 in s` → 15; `15 not in s`. Return 15.

## Complexity
- Time: O(n), where n = len(nums) ≤ 50. One pass to compute the prefix sum, one pass to build the set, and at most n increments in the while loop (each value in nums can be skipped at most once).
- Space: O(n) for the hash set storing up to n distinct integers.

## Edge Cases
- **Single element array** (e.g., `[7]`): prefix sum = 7; if 7 is in the set (it is), increment to 8 and return 8. Works.
- **Entire array is sequential** (e.g., `[1,2,3]`): loop never breaks, sum = 6; 6 not in set → return 6. Works.
- **Prefix sum already missing** (Example 1): while loop body never executes. Works.
- **Duplicates in array**: set deduplicates, so while loop still terminates correctly. Works.
- **All values up to some large number present**: while loop increments until it finds a gap; bounded by n distinct values, so at most n iterations. Works.

Constraints guarantee `nums.length ≥ 1`, so empty input is impossible and not an edge case.

## Possible Improvements
The solution is already optimal for the given constraints (O(n) time, O(n) space). No asymptotic improvement is possible because every element must be inspected at least once to verify the sequential prefix. A micro-optimisation would be to build the set before the prefix loop and reuse it, but that does not change complexity and adds negligible overhead. Variable names are clear; no renaming needed.
