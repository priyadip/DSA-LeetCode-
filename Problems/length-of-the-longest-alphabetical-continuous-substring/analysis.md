# 2414. Length of the Longest Alphabetical Continuous Substring - Solution Analysis

## Problem Understanding
The problem asks for the length of the longest contiguous substring of `s` where each character is exactly one greater than the previous character in the alphabet (e.g., "abc", "xyz"). The input is a string of lowercase letters with length between 1 and 10^5. The output is an integer length. Order matters (strictly increasing by 1), duplicates break continuity, and the substring must be contiguous in `s`. The maximum possible answer is 26 (the whole alphabet), but `s` can be much longer.

## Approach
The solution uses a **single-pass linear scan** (a greedy streak-tracking pattern). It iterates over adjacent character pairs, maintaining a counter `j` for the current number of consecutive increasing pairs. When a pair is consecutive, `j` increments; otherwise, `j` resets to 0. The maximum `j` seen is stored in `ans`. The final answer is `ans + 1` because a streak of `k` consecutive pairs corresponds to a substring of length `k+1`.

Brute force would check all substrings in O(n^2) time. The linear scan achieves O(n) time and O(1) space by exploiting the fact that the condition only depends on adjacent characters, allowing us to extend or reset the current streak in constant time per step. The key insight: **the longest alphabetical continuous substring is exactly one longer than the maximum number of adjacent consecutive pairs**.

## Algorithm
1. Initialize `j = 0` (current streak of consecutive pairs) and `ans = 0` (maximum streak found).
2. Loop `i` from 0 to `len(s)-2` (each adjacent pair `s[i]` and `s[i+1]`).
3. If `ord(s[i]) + 1 == ord(s[i+1])`, increment `j` by 1; else reset `j` to 0.
4. Update `ans = max(ans, j)`.
5. After the loop, return `ans + 1` (convert pair count to substring length).

## Line-by-Line Explanation
- `j = 0`: initializes the current consecutive pair count.
- `ans = 0`: initializes the maximum consecutive pair count found.
- `for i in range(len(s)-1):`: iterates over each index of the first character in adjacent pairs.
- `if ord(s[i])+1 == ord(s[i+1]):`: checks if the two characters are consecutive in the alphabet.
- `j += 1`: extends the current streak by one pair.
- `else:`: the pair breaks the streak.
- `j = 0`: resets the current streak to zero.
- `if j > ans:`: checks if the current streak exceeds the best.
- `ans = j`: updates the best streak.
- `return ans + 1`: converts pair count to substring length (pairs + 1).

## Dry Run
Example 1: `s = "abacaba"` (indices 0:a, 1:b, 2:a, 3:c, 4:a, 5:b, 6:a). Loop `i` from 0 to 5.

| Step | i | s[i] | s[i+1] | Consecutive? | j before | j after | ans before | ans after | Action |
|------|---|------|--------|--------------|----------|---------|------------|-----------|--------|
| 1 | 0 | a | b | True (97+1=98) | 0 | 1 | 0 | 1 | extend streak |
| 2 | 1 | b | a | False | 1 | 0 | 1 | 1 | reset streak |
| 3 | 2 | a | c | False (97+1=98 != 99) | 0 | 0 | 1 | 1 | reset streak |
| 4 | 3 | c | a | False | 0 | 0 | 1 | 1 | reset streak |
| 5 | 4 | a | b | True | 0 | 1 | 1 | 1 | extend streak |
| 6 | 5 | b | a | False | 1 | 0 | 1 | 1 | reset streak |

End: `ans = 1`, return `1 + 1 = 2`. Matches expected output.

## Complexity
- Time: O(n), where n = len(s). The loop runs n-1 times, each iteration does O(1) work.
- Space: O(1), only a few integer variables used.

## Edge Cases
- Single character string (n=1): loop doesn't run, `ans=0`, returns 1. Correct.
- All characters same, e.g., "aaaa": no consecutive pairs, `j` always 0, returns 1. Correct (each single char is a valid substring).
- Entire string is consecutive, e.g., "abcdefghijklmnopqrstuvwxyz": `j` increments to 25, `ans=25`, returns 26. Correct.
- Multiple maximum streaks: e.g., "abcxyz": two streaks of length 3, `ans=2`, returns 3. Correct.
- Non-consecutive increasing by more than 1: e.g., "ace": pairs not consecutive, max length 1. Correct.
- Constraints guarantee n ≥ 1, so empty string is not a case.

Using `zip(s, s[1:])` could make the loop more Pythonic but is not necessary. No algorithmic improvement is needed.
