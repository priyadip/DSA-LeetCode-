# 3875. Construct Uniform Parity Array I - Solution Analysis

## Problem Understanding
We are given an array `nums1` of `n` distinct positive integers. We must build an array `nums2` of the same length where every element has the same parity (all even or all odd). For each index `i` we may either keep `nums1[i]` or replace it with `nums1[i] - nums1[j]` for some `j ≠ i`. The task is to decide whether such a construction is possible. The constraints are small (`n ≤ 100`, values ≤ 100), but the key observation is that the answer does not depend on the actual values at all – it is always possible.

## Approach
The solution uses a **mathematical insight / invariant** pattern.  
Brute force would try all choices of keeping or subtracting for each index, which is exponential. The insight is that for any set of distinct integers we can always achieve uniform parity:
- If there is at least one odd number, we can make every element odd (evens become odd by subtracting that odd; odds stay odd).
- If there are no odd numbers (all even), the array is already uniform.
- The only potential obstacle – a single odd element when targeting even – is avoided by targeting odd instead.
Thus the answer is **always `true`**, so the algorithm reduces to a constant-time return.

## Algorithm
1. Recognize that a uniform parity array can always be constructed for any valid input.
2. Return `True`.
