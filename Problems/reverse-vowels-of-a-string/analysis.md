# 345. Reverse Vowels of a String - Solution Analysis

## Problem Understanding
Given a string `s`, reverse the order of all vowels (a, e, i, o, u, case-insensitive) while keeping consonants and non-alphabetic characters in their original positions. The string length can be up to 300,000, so an O(n) single-pass or two-pass solution is required; O(n²) approaches (e.g., repeated string concatenation) will time out. The input consists of printable ASCII characters, so we only need to handle standard English vowels.

## Approach
This uses the **two pointers** pattern on a mutable array representation of the string. The brute-force approach would collect all vowels, reverse that list, then rebuild the string by iterating again and popping from the reversed list — O(n) time but two full passes and extra O(v) space for the vowel list. The two-pointer approach achieves the same in a single pass with O(1) extra space (aside from the O(n) list conversion required because Python strings are immutable). The key insight: vowels at symmetric positions from the ends should be swapped, so we advance left pointer until a vowel, advance right pointer until a vowel, swap, and repeat until pointers cross.

## Algorithm
1. Convert the string to a list of characters for in-place mutation.
2. Initialize `i = 0` (left pointer) and `j = len(s) - 1` (right pointer).
3. While `i < j`:
   a. Increment `i` until `s[i]` is a vowel or `i >= j`.
   b. Decrement `j` until `s[j]` is a vowel or `i >= j`.
   c. If `i < j`, swap `s[i]` and `s[j]`, then increment `i` and decrement `j`.
4. Join the list back into a string and return it.

## Line-by-Line Explanation
- `vowels = set("aeiouAEIOU")`: Constant-time membership test for vowels; set lookup is O(1) vs O(10) for string `in`.
- `s = list(s)`: Convert immutable string to mutable list so we can swap characters in place.
- `i = 0`: Left pointer starts at the beginning.
- `j = len(s) - 1`: Right pointer starts at the end.
- `while i < j:`: Continue until pointers meet or cross; no work needed when they overlap.
- `while i < j and s[i] not in vowels:`: Advance left pointer past non-vowels, stopping before crossing `j`.
- `i += 1`: Move left pointer forward.
- `while i < j and s[j] not in vowels:`: Advance right pointer backward past non-vowels, stopping before crossing `i`.
- `j -= 1`: Move right pointer backward.
- `if i < j:`: Guard ensures we only swap when distinct vowel positions are found.
- `s[i], s[j] = s[j], s[i]`: Swap the two vowels in place.
- `i += 1`: Move left pointer inward after swap.
- `j -= 1`: Move right pointer inward after swap.
- `return ''.join(s)`: Reconstruct string from the mutated list.

## Complexity
- Time: O(n), where n = len(s). Each pointer traverses the string at most once; every character is examined a constant number of times.
- Space: O(n), because the string is converted to a list of characters (strings are immutable in Python). The vowel set is O(1) (fixed size 10).

## Edge Cases
- **Single character** (`"a"`): i=0, j=0, loop never runs, returns original string.
- **No vowels** (`"bcdfg"`): inner loops advance i to j without swapping; returns original string.
- **All vowels** (`"aeiou"`): pointers meet in the middle after swapping pairs; correctly reversed.
- **Mixed case** (`"AaEe"`): set contains both cases, so `'A'` and `'a'` are both recognised and swapped.
- **Already reversed** (`"uoiea"`): algorithm still performs swaps, producing the same logical reversal (idempotent for palindromic vowel sequences).
- **Maximum length** (3·10⁵): O(n) time and space fit comfortably within limits.

## Possible Improvements
The solution is already optimal for the given constraints. The two-pointer approach achieves the theoretical lower bound of O(n) time and O(n) space (required by Python's string immutability). The vowel lookup uses a pre-computed set for O(1) membership tests. No algorithmic or material constant-factor improvements are available.
