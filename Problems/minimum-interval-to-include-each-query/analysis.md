## Problem Understanding
The problem requires finding the size of the smallest interval that contains each query value. The given intervals are defined by a start and end value, and each query value must fall within one of these intervals. If no such interval exists, the answer is -1. The intervals and queries are provided as input, with constraints on the number of intervals, queries, and the range of their values.

## Approach
The solution uses a combination of sorting and a heap data structure. The intervals are sorted by their start values, and the queries are sorted by their values. A min-heap is used to store the intervals that contain the current query value, with the heap ordered by the size of the intervals. This approach allows for efficient searching and insertion of intervals as the query values are processed.

## Algorithm
1. Sort the intervals by their start values.
2. Sort the queries by their values, along with their original indices.
3. Initialize an array to store the answers and a min-heap to store the intervals.
4. Iterate through the sorted queries, and for each query:
   - Add all intervals that start at or before the current query value to the heap.
   - Remove all intervals from the heap that end before the current query value.
   - If the heap is not empty, the size of the smallest interval in the heap is the answer for the current query.
5. Return the array of answers.
