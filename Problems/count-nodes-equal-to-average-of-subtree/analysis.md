# 2265. Count Nodes Equal to Average of Subtree - Solution Analysis

## Problem Understanding
Given a binary tree root, count nodes where the node's value equals the floor of the average of all values in its subtree (the node plus all descendants). The average is computed as integer division (sum // count). Constraints: 1 to 1000 nodes, values 0 to 1000. The tree is non-empty by constraints.

## Approach
The solution uses **post-order depth-first search (DFS)** on a binary tree. The brute-force approach would compute the average for each node by traversing its entire subtree separately, costing O(n²) time in the worst case (e.g., a skewed tree). The chosen approach computes subtree sum and size bottom-up in a single pass, returning both values to the parent so each node is visited exactly once. The key insight: a node's subtree sum and count are the sum of its children's sums and counts plus its own value, enabling O(n) time.

## Algorithm
1. Initialize a counter `ans = 0`.
2. Define a recursive function `dfs(node)` that returns `(subtree_sum, subtree_count)`.
3. If `node` is `None`, return `(0, 0)`.
4. Recursively call `dfs` on `node.left` and `node.right` to get `(left_sum, left_count)` and `(right_sum, right_count)`.
5. Compute `total_sum = left_sum + right_sum + node.val` and `total_count = left_count + right_count + 1`.
6. If `node.val == total_sum // total_count`, increment `ans`.
7. Return `(total_sum, total_count)` to the caller.
8. Call `dfs(root)` and return `ans`.

## Line-by-Line Explanation
- `self.ans = 0`: accumulator for qualifying nodes, stored on the instance so the nested function can modify it.
- `def dfs(node):`: post-order traversal returning sum and count of the subtree rooted at `node`.
- `if not node: return 0, 0`: base case — empty subtree contributes zero sum and zero nodes.
- `left_sum, left_count = dfs(node.left)`: obtain aggregate data from left subtree.
- `right_sum, right_count = dfs(node.right)`: obtain aggregate data from right subtree.
- `total_sum = left_sum + right_sum + node.val`: sum of current subtree.
- `total_count = left_count + right_count + 1`: size of current subtree (including this node).
- `if node.val == total_sum // total_count: self.ans += 1`: check the average condition using floor division.
- `return total_sum, total_count`: propagate aggregates upward.
- `dfs(root)`: kick off the traversal.
- `return self.ans`: final count.

## Complexity
- Time: O(n), where n is the number of nodes (1 ≤ n ≤ 1000). Each node is visited once, and each visit does O(1) work.
- Space: O(h) recursion stack, where h is tree height. In worst case (skewed tree) h = n, so O(n); average case O(log n). The `self.ans` integer is O(1).

## Edge Cases
- Single node tree (`root = [1]`): returns 1 because sum=1, count=1, avg=1 matches.
- All nodes have the same value (e.g., all 5): every node matches because average of identical values equals that value.
- Large values up to 1000: sum fits in Python int (unbounded), no overflow.
- Tree with only left children (skewed): recursion depth up to 1000, within Python's default recursion limit (~1000) but borderline; could hit `RecursionError` if limit is lower or constraints were larger.

## Possible Improvements
The solution is already optimal in time O(n) and space O(h) for the given constraints. A minor improvement: replace the instance variable `self.ans` with a nonlocal variable or return the count alongside sum/count to avoid side effects, e.g., `return total_sum, total_count, count`. This makes the function pure and thread-safe. For the stated constraints (n ≤ 1000), recursion depth is acceptable; if constraints grew, an iterative post-order traversal with an explicit stack would avoid recursion limits.
