# 485. Max Consecutive Ones - Solution Analysis

## Problem Understanding
Given a binary array `nums` containing only 0s and 1s, return the length of the longest contiguous subarray consisting entirely of 1s. The array length is up to 10^5, so an O(n) single-pass solution is required; order matters because we need consecutive elements, and the answer is 0 if no 1s exist.

## Approach
The solution uses a **single-pass running counter** (a degenerate sliding window). The brute-force approach would check every possible subarray in O(n²) time. Instead, we maintain the length of the current streak of 1s (`cn`) and the maximum streak seen so far (`ans`). When a 1 is encountered, the current streak extends; when a 0 is encountered, the streak breaks and resets to 0. The key insight: **only the current streak length and the global maximum are needed; past streaks can be discarded once a 0 appears.**

## Algorithm
1. Initialize `cn = 0` (current consecutive 1s) and `ans = 0` (maximum found).
2. For each `num` in `nums`:
   - If `num == 1`: increment `cn` and update `ans = max(ans, cn)`.
   - Else (`num == 0`): reset `cn = 0`.
3. Return `ans`.

## Line-by-Line Explanation
- `cn = ans = 0`: Initialize both the running streak counter and the global maximum to 0.
- `for num in nums:`: Iterate through each element of the input array once.
- `if num == 1:`: Check if the current element continues a streak of 1s.
- `cn += 1`: Extend the current streak by one.
- `ans = max(ans, cn)`: Update the global maximum if the current streak exceeds it.
- `else:`: The element is 0, so any ongoing streak ends.
- `cn = 0`: Reset the running streak counter to 0.
- `return ans`: After the loop, `ans` holds the length of the longest consecutive 1s.

## Dry Run
Example 1: `nums = [1,1,0,1,1,1]`

| Step | i | num | cn | ans | Action |
|------|---|-----|----|-----|--------|
| 1 | 0 | 1 | 1 | 1 | streak=1, max=1 |
| 2 | 1 | 1 | 2 | 2 | streak=2, max=2 |
| 3 | 2 | 0 | 0 | 2 | reset streak |
| 4 | 3 | 1 | 1 | 2 | streak=1, max unchanged |
| 5 | 4 | 1 | 2 | 2 | streak=2, max unchanged |
| 6 | 5 | 1 | 3 | 3 | streak=3, max=3 |

Return 3.

## Complexity
- Time: O(n), where n = len(nums). The loop visits each element exactly once, and all operations inside are O(1).
- Space: O(1). Only two integer variables (`cn`, `ans`) are used regardless of input size.

## Edge Cases
- **All 1s** (e.g., `[1,1,1]`): `cn` grows to n, `ans` tracks it correctly → returns n.
- **All 0s** (e.g., `[0,0,0]`): `cn` stays 0, `ans` stays 0 → returns 0.
- **Single element** `[1]` or `[0]`: loop runs once, logic holds → returns 1 or 0.
- **Maximum length 10^5**: O(n) time and O(1) space easily satisfy constraints.
- **Alternating 1s and 0s** (e.g., `[1,0,1,0,1]`): correctly returns 1.

## Possible Improvements
The solution is already optimal for the given constraints: any algorithm must inspect every element at least once, so Ω(n) time is a lower bound, and O(1) auxiliary space is minimal. Variable names could be more descriptive (`current_streak`, `max_streak`), but this is purely stylistic and does not affect correctness or complexity. No algorithmic improvement exists.
