# 443. String Compression - Solution Analysis

## Problem Understanding
Given a character array `chars`, compress consecutive repeating characters in-place using run-length encoding: each group becomes the character followed by its count (if count > 1). The compressed result must overwrite the original array starting at index 0, and the function returns the new length. Only O(1) extra space is allowed. Constraints: 1 ≤ n ≤ 2000, characters are alphanumeric or symbols. Order matters; groups are strictly consecutive.

## Approach
**Two Pointers (Read/Write)**. The read pointer `i` scans the array to identify each consecutive group; the write pointer `ans` records the compressed output at the front of the same array. This avoids extra space and achieves O(n) time. Brute force would build a new string then copy back, costing O(n) extra space. The key insight is that the write position never overtakes the read position, so in-place overwrite is safe.

## Algorithm
1. Initialize `n = len(chars)`, read pointer `i = 0`, write pointer `ans = 0`.
2. While `i < n`:
   a. Record current character `ch = chars[i]` and group start `j = i`.
   b. Advance `i` while `i < n` and `chars[i] == ch` to find group end.
   c. Compute `count = i - j`.
   d. Write `ch` at `chars[ans]`, increment `ans`.
   e. If `count > 1`, convert `count` to string and write each digit to `chars[ans]`, incrementing `ans` each time.
3. Return `ans` as the new length.

## Line-by-Line Explanation
- `n = len(chars)`: cache length for loop bound.
- `i = 0`: read pointer starts at first character.
- `ans = 0`: write pointer starts at beginning of array.
- `while i < n:`: process until all characters consumed.
- `ch = chars[i]`: current group's character.
- `j = i`: remember group start index.
- `while i < n and chars[i] == ch: i += 1`: scan to end of this consecutive group.
- `count = i - j`: group length.
- `chars[ans] = ch; ans += 1`: write the character itself.
- `if count > 1:`: only append count when group length > 1.
- `for digit in str(count): chars[ans] = digit; ans += 1`: write each digit of the count as separate characters.

## Dry Run
Example 1: `chars = ["a","a","b","b","c","c","c"]`

| Step | i | j | ch | count | ans before | chars[0:ans] after write | Action |
|------|---|---|----|-------|------------|--------------------------|--------|
| 1 | 0 | 0 | a | - | 0 | - | start group 'a' |
| 2 | 2 | 0 | a | 2 | 0 | ['a'] | write 'a' |
| 3 | 2 | 0 | a | 2 | 1 | ['a','2'] | write digits of 2 |
| 4 | 2 | 2 | b | - | 2 | - | start group 'b' |
| 5 | 4 | 2 | b | 2 | 2 | ['a','2','b'] | write 'b' |
| 6 | 4 | 2 | b | 2 | 3 | ['a','2','b','2'] | write digits of 2 |
| 7 | 4 | 4 | c | - | 4 | - | start group 'c' |
| 8 | 7 | 4 | c | 3 | 4 | ['a','2','b','2','c'] | write 'c' |
| 9 | 7 | 4 | c | 3 | 5 | ['a','2','b','2','c','3'] | write digits of 3 |
| End | 7 | - | - | - | 6 | first 6 = ["a","2","b","2","c","3"] | return 6 |

## Complexity
- Time: O(n), where n = len(chars). Each character is visited once by `i`; each digit of each count is written once by `ans`. Total operations ≤ 2n.
- Space: O(1) extra. Only a few integer variables and the temporary string `str(count)` (max length 4 since n ≤ 2000) are used, which is constant.

## Edge Cases
- Single character (`["a"]`): count = 1, only character written, returns 1.
- All same character (`["a"]*2000`): count = 2000, writes 'a','2','0','0','0', returns 4.
- Count ≥ 10 (e.g., Example 3): `str(count)` correctly splits into multiple digits.
- Already compressed (no consecutive duplicates): each group length 1, array unchanged, returns n.
- Mixed case / symbols / digits: treated as opaque characters, equality works.

## Possible Improvements
The solution is already optimal for the given constraints: O(n) time, O(1) space, single pass. Variable names are clear (`i` for read, `ans` for write). One minor style point: `j` could be named `group_start` for readability, but the current names are standard for two-pointer patterns. No redundant passes or structures exist.
