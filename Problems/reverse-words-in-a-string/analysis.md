# 151. Reverse Words in a String - Solution Analysis

## Problem Understanding
Reverse the order of words in a string where words are sequences of non-space characters separated by at least one space. The input may contain leading, trailing, or multiple consecutive spaces; the output must have exactly one space between words and no leading/trailing spaces. Constraints guarantee at least one word exists and length ≤ 10⁴.

## Approach
**Pattern:** Built-in string manipulation / library-based parsing.  
Python's `str.split()` without arguments splits on arbitrary whitespace runs and discards empty results, which directly handles all space-normalization requirements. The brute-force alternative would manually scan characters to extract words (O(n) time, O(n) space, but verbose and error-prone). The chosen approach delegates the parsing to a highly optimized C implementation, buying correctness and brevity.

**Key insight:** `split()` + `join()` + slice reversal expresses the entire specification in three standard library calls.

## Algorithm
1. Split the input string on whitespace via `s.split()`, producing a list of words with no empty strings.
2. Reverse the list using slice notation `[::-1]`.
3. Join the reversed list with a single space via `' '.join(...)`.
4. Return the joined string.

## Line-by-Line Explanation
- `wordlist = s.split()`: Splits `s` on any run of whitespace, returning only non-empty words; leading/trailing/multiple spaces are automatically discarded.
- `return ' '.join(wordlist[::-1])`: Reverses the word list and concatenates with exactly one space between each word.

## Dry Run
Example: `s = "  hello world  "`

| Step | s.split()        | wordlist[::-1]     | ' '.join(...) |
|------|------------------|--------------------|---------------|
| 1    | ["hello", "world"] | ["world", "hello"] | "world hello" |

## Complexity
- **Time:** O(n) — `split()` scans the string once, slice reversal touches each word once, `join()` scans all characters again. n = len(s).
- **Space:** O(n) — the word list and the output string each store O(n) characters.

## Edge Cases
- **Leading/trailing spaces:** `split()` discards them.
- **Multiple spaces between words:** `split()` treats any run as a single delimiter.
- **Single word:** list length 1, reversal is a no-op, `join` returns the word unchanged.
- **All spaces:** Impossible per constraints (at least one word guaranteed).

## Possible Improvements
The solution is already optimal for Python: O(n) time and space are unavoidable since the output itself is size O(n). The follow-up asks for in-place O(1) extra space with a mutable string type; Python strings are immutable, so that follow-up does not apply here. No material improvements exist — the code is idiomatic, correct, and asymptotically optimal.
