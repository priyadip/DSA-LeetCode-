# 139. Word Break - Solution Analysis

## Problem Understanding
Given a string `s` (length 1–300) and a list of unique words `wordDict` (up to 1000 words, each length 1–20), determine if `s` can be split into a sequence of one or more dictionary words, with reuse allowed. The order of characters must be preserved exactly. The constraints (especially `n ≤ 300`) make an O(n²) or O(n³) dynamic programming approach feasible.

## Approach
The solution uses **Dynamic Programming on prefixes** (1D DP).  
`dp[i]` stores whether the prefix `s[:i]` can be segmented. The recurrence: `dp[i] = True` iff there exists `j < i` such that `dp[j]` is True and `s[j:i]` is in the dictionary.  
Brute force would try all partitions (exponential). DP reuses subproblem results, reducing the work to polynomial time.  
**Key insight:** A prefix is segmentable exactly when it can be split into a segmentable prefix and a dictionary word.

## Algorithm
1. Convert `wordDict` to a set `wordSet` for O(1) lookups.
2. Let `n = len(s)`. Create boolean array `dp` of size `n+1`, initialise all `False` except `dp[0] = True` (empty prefix is segmentable).
3. For `i` from 1 to `n`:
   - For `j` from 0 to `i-1`:
     - If `dp[j]` is True and `s[j:i]` in `wordSet`:
       - Set `dp[i] = True` and break the inner loop.
4. Return `dp[n]`.

## Line-by-Line Explanation
- `wordSet = set(wordDict)`: enables O(1) word existence checks.
- `n = len(s)`: length of the input string.
- `dp = [False] * (n + 1)`: DP table where `dp[i]` will indicate if `s[:i]` can be segmented.
- `dp[0] = True`: base case – empty string is trivially segmentable.
- `for i in range(1, n + 1):`: iterate over all prefix lengths.
- `for j in range(i):`: try every possible split point `j` (0 ≤ j < i).
- `if dp[j] and s[j:i] in wordSet:`: if prefix up to `j` works and the substring `s[j:i]` is a dictionary word.
- `dp[i] = True`: mark current prefix as segmentable.
- `break`: no need to check further `j` for this `i`.
- `return dp[n]`: answer for the whole string.

## Dry Run
Example: `s = "leetcode"`, `wordDict = ["leet","code"]` (n=8).

| i | j checked (dp[j], substring)                     | dp[i] |
|---|--------------------------------------------------|-------|
| 1 | j=0 (T, "l")                                     | False |
| 2 | j=0 (T, "le"), j=1 (F, "e")                      | False |
| 3 | j=0 (T, "lee"), j=1 (F, "ee"), j=2 (F, "e")      | False |
| 4 | j=0 (T, "leet") → in set                         | True  |
| 5 | j=0 (T, "leetc"), j=4 (T, "c")                   | False |
| 6 | j=0 (T, "leetco"), j=4 (T, "co")                 | False |
| 7 | j=0 (T, "leetcod"), j=4 (T, "cod")               | False |
| 8 | j=0 (T, "leetcode"), j=4 (T, "code") → in set    | True  |

Result: `dp[8] = True`.

## Complexity
- **Time:** O(n³) worst-case, where n = len(s). The double loop runs O(n²) times, and each substring extraction `s[j:i]` takes O(i−j) time. Summed over all iterations this is O(n³). (With the constraint `max(word length) ≤ 20`, adding a length check would reduce it to O(n²) or effectively O(n).)
- **Space:** O(n) for the `dp` array, plus O(total characters in wordDict) for the set.

## Edge Cases
- **Single character, word in dict:** `dp[1]` becomes True via `j=0`.
- **No valid segmentation:** all `dp[i]` remain False, returns False.
- **Reusing words:** allowed because `dp[j]` can be True multiple times (e.g., "applepenapple").
- **Words longer than s:** never match because substring length ≤ n.
- **All same letters, large n:** DP handles overlapping matches correctly.
- Empty string not possible per constraints (n ≥ 1).

## Possible Improvements
- **Limit inner loop by max word length:** compute `max_len = max(len(w) for w in wordDict)` and iterate `j` from `max(0, i - max_len)` to `i-1`. This reduces time to O(n · max_len) = O(n) (since max_len ≤ 20 is constant), a significant asymptotic improvement.
- **Rename `dp` to `can_segment`** for clarity.
- The current solution is correct and passes within constraints, but the missing length optimisation makes it theoretically slower than necessary.
