# 36. Valid Sudoku - Solution Analysis

## Problem Understanding
Validate a 9×9 Sudoku board by checking that no row, column, or 3×3 sub-box contains duplicate digits 1–9. Empty cells ('.') are ignored. The board size is fixed at 9×9, so the algorithm runs in constant time and space relative to the input dimensions, though we express complexity in terms of N=9 for generality.

## Approach
**Pattern:** Hash sets for duplicate detection across multiple partitions.  
**Why it fits:** Each cell belongs to exactly one row, one column, and one 3×3 box. We must verify that no digit repeats in any of these three partitions. A brute-force approach would scan each row, column, and box separately (three passes, or nested loops per partition), costing O(N³) for an N×N board. By maintaining a set per row, per column, and per box, we validate all three constraints in a single pass over the board.  
**Key insight:** The box index for cell (r, c) can be computed as `(r // 3) * 3 + (c // 3)`, mapping the nine 3×3 regions to indices 0–8.

## Algorithm
1. Create three arrays of 9 empty sets: `rows`, `cols`, `boxes`.
2. For each row `r` from 0 to 8:
   a. For each column `c` from 0 to 8:
      i. If `board[r][c] == '.'`, skip.
      ii. Let `num = board[r][c]`.
      iii. Compute `box = (r // 3) * 3 + (c // 3)`.
      iv. If `num` exists in `rows[r]`, `cols[c]`, or `boxes[box]`, return `False`.
      v. Add `num` to `rows[r]`, `cols[c]`, and `boxes[box]`.
3. Return `True`.

## Line-by-Line Explanation
- `rows = [set() for _ in range(9)]`: one set per row to record digits seen.
- `cols = [set() for _ in range(9)]`: one set per column.
- `boxes = [set() for _ in range(9)]`: one set per 3×3 box.
- `for r in range(9):`: iterate rows.
- `for c in range(9):`: iterate columns.
- `if board[r][c] == ".": continue`: ignore empty cells.
- `num = board[r][c]`: current digit as a string.
- `box = (r // 3) * 3 + (c // 3)`: compute 0–8 box index.
- `if num in rows[r]: return False`: duplicate in row.
- `if num in cols[c]: return False`: duplicate in column.
- `if num in boxes[box]: return False`: duplicate in box.
- `rows[r].add(num)`: mark digit seen in this row.
- `cols[c].add(num)`: mark digit seen in this column.
- `boxes[box].add(num)`: mark digit seen in this box.
- `return True`: no conflicts found.

## Complexity
- **Time:** O(1) — the board is fixed at 9×9 (81 cells). In terms of N=9: O(N²) because each cell is visited once and set operations are O(1).
- **Space:** O(1) — three arrays of 9 sets, each holding at most 9 elements. In terms of N: O(N²).

## Edge Cases
- **All '.'** — returns `True` (no duplicates).
- **Completely filled valid board** — returns `True`.
- **Duplicate in row, column, or box** — returns `False` at first detection.
- **Multiple conflicts** — returns `False` on the earliest one encountered in row-major order.
- Constraints guarantee 9×9 and only '1'–'9' or '.', so no handling for other sizes or characters is needed.

## Possible Improvements
The solution is already optimal for the given constraints. A constant-factor improvement would be to use bitmasks (integers 0–511) instead of sets, reducing overhead, but the current approach is clear, Pythonic, and runs well within limits. No algorithmic improvement is possible because every cell must be examined at least once.
